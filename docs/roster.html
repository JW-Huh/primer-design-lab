분반 코드 만들기 (교수자용)

수강생 학번 명단을 넣으면, 그 반에서 8개 유전자가 가장 고르게 나뉘는 5자리 분반 코드를 찾아 줍니다. 학생은 핀볼에 학번과 이 코드를 넣습니다. 명단은 이 브라우저 안에서만 쓰이고 어디에도 저장·전송되지 않습니다.

코드를 넣고 확인을 누르면 새로 찾지 않고 그 코드의 배정을 보여 줍니다. 수강생이 바뀌었을 때 씁니다.

분반 코드

학번별 배정

쓰는 법

  1. 분반마다 명단을 넣고 코드 찾기를 누릅니다. 코드는 매번 새로 찾으므로, 정한 코드는 적어 둡니다.
  2. 수업 때 학생에게 코드만 알려 줍니다. 학생은 핀볼의 분반 코드 칸에 넣습니다.
  3. 명단에 없던 학생이 와도 같은 코드로 배정은 나옵니다. 고르게 나뉘는 것은 명단에 있던 학생 기준입니다.
  4. 코드를 비우면 핀볼은 학번만으로 배정합니다(연속된 학번은 고르게, 띄엄띄엄한 학번은 무작위처럼).
명단은 이 페이지를 닫으면 사라집니다.
